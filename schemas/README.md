# schemas/

JSON Schema (draft-07) của định dạng project (`schemaVersion` `0.1.x` đến `0.6.x` và `1.0.x`). Nguồn chuẩn cho cả bộ kiểm tra TypeScript (`packages/project-schema`) và C++ (`core/project-manager`). Ý nghĩa trường: [specs/002-vertical-slice/data-model.md](../specs/002-vertical-slice/data-model.md); mã lỗi và luật liên file: [contracts/project-format.md](../specs/002-vertical-slice/contracts/project-format.md).

`logging.schema.json` (feature 003): cấu hình lưu trữ dữ liệu Tag `logging.json`, trỏ tới bằng `loggingFile` của `project.json`. Nhóm lưu trữ (theo chu kỳ hoặc theo thay đổi, thời hạn lưu, Tag và cột), kết nối DB ngoài (MySQL/MariaDB, SQL Server, PostgreSQL, InfluxDB) **không có** mật khẩu/token. Luật liên file `E_LOG_*` và cảnh báo `W_LOG_*`: [specs/003-data-logging/contracts/logging-config.md](../specs/003-data-logging/contracts/logging-config.md).

Bộ kiểm TS và C++ chọn cùng bộ cho `1.0.x` và `1.1.x`; phần chỉ có ở 1.1 do luật `E_LAYOUT_VERSION` kiểm. Luật: `packages/project-schema/src/rules-11.ts` và bản C++ `core/project-manager/rules_11`. Luật ngoài schema (`files` sắp tăng dần theo byte UTF-8, không trùng, không có `matscada.json`; MAJOR của `formatVersion` phải là 1): contract §3, §8a.
