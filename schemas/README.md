# schemas/

JSON Schema (draft-07) của định dạng project **v0** (`schemaVersion` `0.1.x`, `0.2.x`, `0.3.x`). Nguồn chuẩn cho cả bộ kiểm tra TypeScript (`packages/project-schema`) và C++ (`core/project-manager`). Ý nghĩa trường: [specs/002-vertical-slice/data-model.md](../specs/002-vertical-slice/data-model.md); mã lỗi và luật liên file: [contracts/project-format.md](../specs/002-vertical-slice/contracts/project-format.md).

`logging.schema.json` (feature 003): cấu hình lưu trữ dữ liệu Tag `logging.json`, trỏ tới bằng `loggingFile` của `project.json`. Nhóm lưu trữ (theo chu kỳ hoặc theo thay đổi, thời hạn lưu, Tag và cột), kết nối DB ngoài (MySQL/MariaDB, SQL Server, PostgreSQL, InfluxDB) **không có** mật khẩu/token. Luật liên file `E_LOG_*` và cảnh báo `W_LOG_*`: [specs/003-data-logging/contracts/logging-config.md](../specs/003-data-logging/contracts/logging-config.md).

**Định dạng 0.4 (feature 008).** Các schema ở thư mục gốc `schemas/` là bản **0.4.0** (`$id` `.../0.4.json`); bản **0.3.0** đóng băng ở `schemas/0.3/` (8 file: `project`, `tag`, `screen`, `binding`, `connections`, `value-table`, `watch-table`, `logging`), nội dung đúng như bản gốc trước 0.4. Validator TS chọn bộ schema theo `schemaVersion` của `project.json` (0.1, 0.2, 0.3, 0.4); runtime 0.7.0 nhận 0.4 và `minRuntimeVersion` của project 0.4 là `0.7.0`. Khác 0.3: `binding.schema.json` thêm các **đích** (`geometry.clipLevel`, `transform.rotate`, `transform.translateX/Y`, `transform.scale`, `effect.blink`, `effect.flow`), các **tham số** của hoạt ảnh (`pivot`, `animation: spin`, `period` 400 đến 5.000 ms, `speed` 0 đến 300, `minOpacity`, `dash`, `direction`, `byValueSign`, `onBadQuality`...), các **phép biến đổi** mới (khoảng `rangeMap`, rời rạc, bảng giá trị cho màu) và khóa `events.click` (hành động `navigate`, `popup`, `closePopup`, `write`, `toggle`, `pulse`); `screen.schema.json` nới trần item `svg` mỗi màn hình từ 8 lên 64 (luật `E_LIMIT` kiểm, schema chỉ kiểm khung); các file còn lại chỉ đổi phiên bản. Hai binding cùng đích trên một phần tử, UID mồ côi (`E_REF_UID`), tham số ngoài khoảng và hành động ghi thiếu xác nhận là **luật** (`rules-04.ts` và bản C++), không phải schema. Hợp đồng: `specs/008-svg-import-binding/contracts/project-format-0.4.md`, `binding-animation.md`, `svg-events.md`; quyết định: [ADR-024](../docs/adr/024-binding-animation-0.4.md), [ADR-025](../docs/adr/025-svg-element-events.md). Vector chung: `tests/project-vectors/v04-*`, `tests/migration-vectors/*-0.3to0.4/`. Studio nâng 0.1, 0.2 và 0.3 lên 0.4 trong bộ nhớ (hộp thoại Nâng cấp), chỉ ghi đĩa khi bấm Lưu và sao lưu bản cũ trước.

**Định dạng 0.3 (feature 007).** Các schema ở `schemas/0.3/` (trước 008 ở thư mục gốc) là bản **0.3.0** (`$id` `.../0.3.json`); bản **0.2.0** đóng băng ở `schemas/0.2/` (cả 8 file, kiểm bằng SHA-256 ở `meta-schema.test.ts`), bản 0.1 ở `schemas/0.1/`. Validator TS chọn bộ schema theo `schemaVersion` của `project.json` (0.1, 0.2, 0.3). Khác 0.2: `screen.schema.json` là danh sách item tuyệt đối (`kind`, `size`, `fitMode`, `items` gồm item `svg` hoặc `widget`; khóa 0.2 `svgFile`, `bindingFile`, `viewBox`, `elements` ở cấp màn hình bị từ chối); `project.schema.json` thêm `navigation` và bỏ trần 32 màn hình (luật `E_LIMIT` kiểm); `binding.schema.json` thêm `itemId` tùy chọn; các file còn lại chỉ đổi phiên bản. Schema chỉ kiểm khung: id item, `size`, `kind`, loại widget, thuộc tính, khe Tag, hành động, giới hạn số lượng do luật (`rules-03.ts`, và bản C++) kiểm với mã lỗi riêng. **`widgets.catalog.json`** là danh mục 15 loại widget (khe Tag, thuộc tính, sự kiện, vai trò), nguồn duy nhất cho validator TS và C++, inspector và Toolbox của Studio, `<mat-screen>`; hợp đồng: `specs/007-screens-widgets/contracts/widget-catalog.md`. Vector chung: `tests/project-vectors/v03-*`, `tests/widget-catalog-vectors/`, `tests/migration-vectors/*-0.2to0.3/`. Studio nâng 0.1 và 0.2 lên 0.3 trong bộ nhớ (`migrate02to03`, `migrateTo03`), chỉ ghi đĩa khi bấm Lưu và sao lưu bản cũ trước. `tools/gen-schemas-02.mjs` không còn dùng được: nó ghi đè schema ở thư mục gốc, nay là 0.3.

**Định dạng 0.2 (feature 006).** Các schema ở `schemas/0.2/` (trước đây ở thư mục gốc) là bản **0.2.0** (`project`, `tag`, `screen`, `binding`, `logging` và các file mới); đáng chú ý: `project.schema.json`, `tag.schema.json` (Tag v1: loại, địa chỉ, kiểu dữ liệu, scaling, quyền R/RW, Tag nội bộ, Tag tính toán), `connections.schema.json` (kênh Modbus TCP/RTU và thiết bị trường), `value-table.schema.json` (Bảng giá trị), `watch-table.schema.json` (Bảng theo dõi). Bản **0.1** giữ nguyên ở `schemas/0.1/` (project, tag, screen, binding, logging) để validator đọc project cũ. `protocol-version.json` ghi runtime hỗ trợ project `0.1`, `0.2` và `0.3`. Studio nâng project 0.1 lên 0.2 trong bộ nhớ (`packages/project-schema/src/migrate.ts`), chỉ ghi đĩa khi bấm Lưu và sao lưu bản 0.1 trước. Hợp đồng: `specs/006-tags-modbus/contracts/`, ADR-004 và [ADR-017](../docs/adr/017-tag-engine-v1.md). `tools/gen-schemas-02.mjs` là công cụ một lần dựng 0.2 từ `schemas/0.1` (không chạy trong CI; chạy lại thì ghi đè schema ở thư mục gốc).

`protocol-version.json`: phiên bản giao thức live và định dạng project mà runtime hiện tại hỗ trợ.

`package-manifest.schema.json` (feature 005): manifest `matscada.json` của gói project `.matscada`, định dạng 1.x. Khóa lạ ở cấp đầu, trong `project` và `generator` được bỏ qua (bản MINOR sau thêm khóa được); mỗi mục của `files` có đúng ba khóa `path`, `size`, `sha256`. Schema không đặt pattern cho `files[].path`: đường dẫn kiểm bằng luật §5 của [contracts/matscada-package.md](../specs/005-device-online/contracts/matscada-package.md) (`E_PKG_PATH`, `E_PKG_TYPE`). Bộ đọc C++ (`core/package`) kiểm bằng valijson; Studio (Rust) kiểm cùng luật bằng serde. Luật ngoài schema (`files` sắp tăng dần theo byte UTF-8, không trùng, không có `matscada.json`; MAJOR của `formatVersion` phải là 1): contract §3, §8a.

Gói và manifest dùng chung cho C++, Rust và TS: vector ở `tests/package-vectors/` (`node tests/package-vectors/generate.mjs` sinh lại; `--out` sinh các gói lớn không commit). Tập file của gói phải đúng bằng tập file mà project tham chiếu: file thừa không tham chiếu làm digest của gói khác digest runtime tính từ project, và lần nạp xuống bị quay về.

Đổi schema: tăng phiên bản theo ADR-004, cập nhật cả hai bộ kiểm tra và `tests/project-vectors/`.
