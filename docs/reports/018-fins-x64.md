# Driver Omron FINS: số đo x64 và kiểm armhf (feature 018)

Ngày đo: 2026-10-23, máy dev Windows 11, Docker Desktop (image `mat-armhf`, runtime x64 Release), rig `tests/driver-it/compose-fins.yaml` (giả lập `tools/fins-sim` trong container Node 22 cùng mạng bridge). **Chưa thử với PLC Omron thật; chưa đo trên BL335.** Số x64 chỉ để so tương đối với Modbus và để thấy chi phí của driver; ngân sách Constitution III đo trên BL335.

## Tải 500 Tag, chu kỳ 1 s, 10 client (`tools/driver-it.ps1 -Scenario fins-load -Seconds 60 -Clients 10`)

Project `bench-500-fins`: một kênh FINS/UDP, 250 Tag liền (D1000–D1249) và 250 Tag rời (D5000, D5020, …, cách 20 word). Mỗi Tag đổi giá trị mỗi giây (ramp của giả lập). Kết quả JSON: [018-fins-load-x64.json](018-fins-load-x64.json).

| Đại lượng | FINS/UDP | Modbus TCP (cùng bản dựng, cùng tải, `load`) |
|---|---|---|
| CPU trung bình (một lõi) | 0,4 % | 0,4 % |
| CPU cao nhất trong 5 s | 0,6 % | 1,4 % |
| RSS lớn nhất | 16,2 MB | 15,5 MB |
| Lệnh mỗi giây | 4,9 (một 0101 250 word, bốn 0104 ≤ 64 phần tử) | — |
| Chu kỳ thật của Tag | 1.009,7 ms | 1.010 ms |
| Mất thứ tự ở client | 0 | 0 |

Chênh RSS 0,7 MB nằm trong dao động giữa hai lần chạy (Modbus đo ngay sau FINS, cùng bản dựng `C:\build\fins-x64`). Driver FINS giữ một luồng 256 KiB mỗi kênh, bộ đệm một khung (≤ 2 KiB) và kế hoạch đọc tính một lần khi kết nối.
