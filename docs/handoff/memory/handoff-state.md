Ngày 2026-10-16 người dùng chuyển sang máy mới (macOS). Trạng thái hiện hành, việc còn lại, bẫy môi trường và quyết định đã chốt nằm ở **`docs/handoff/gd5-to-gd6.md`** (đọc đầu tiên) và prompt khởi động ở `docs/handoff/PROMPT.md`.

**Why:** các memory `v2-gd1-status`, `sprint1-handoff`, `feature003-status` và `roadmap-v2-proposal` được viết khi GĐ 1 đang làm (2026-10-11) nên đã cũ; chúng chỉ còn là lịch sử quyết định. Trạng thái thật: GĐ 0–5 xong (features 001–010, đã gộp vào `main`), runtime 0.9.0 / Studio 0.8.0 / project 0.6.0 / Constitution 2.0.2, GĐ 6 (feature 011) chưa bắt đầu.

**How to apply:** khi memory cũ mâu thuẫn với `docs/handoff/gd5-to-gd6.md` hoặc mã hiện tại thì tin tài liệu bàn giao và mã. Cập nhật tài liệu bàn giao khi trạng thái đổi, đừng dồn vào memory.
